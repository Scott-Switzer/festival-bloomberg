# C3 / Goldenvoice-Level Gap Matrix — product capability comparison

Compare PRODUCT CAPABILITY against professional music-data products — not
stolen data. "THEM" is the strongest relevant category capability;
"US TODAY" is what this repository can actually do with its live warehouse +
research corpus (not aspirational).

Differentiation thesis: **live-entertainment data + source provenance +
point-in-time research + financial analysis + operations research** — not
another social-media dashboard.

## Verdict

The gap to C3/Goldenvoice-level is now primarily **proprietary data**
(commercial outcomes, dense venue/attention panels, festival billing depth),
not basic product engineering. The workflow surface (discover → compare →
shortlist → scenario → evidence) exists and is honest about UNKNOWNs.
